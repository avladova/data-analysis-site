## Задания

1. Оценка среднего IQ студентов: используя ЦПТ, оценить минимальное число студентов для точности ±1 с вероятностью ≥0.95 при σ≤10.
2. Для выборки n=180 несмещённая точечная оценка дисперсии 0.5768. Построить ДИ для дисперсии на уровне доверия 0.97.
3. Дан набор данных (176 значений). Считая выборку из нормальной генеральной совокупности, построить ДИ для среднего на уровне доверия 0.97.
4. Дан "грязный" набор данных с пропусками (NA) и мусорными значениями. Используя Excel/R, очистить от нечисловых значений и пропусков, вычислить: объём очищенной выборки, межквартильный размах, стандартное отклонение, нижнюю границу нормы, число выбросов. Дополнительно очистить от выбросов и вычислить: объём, квантиль 0.62, эксцесс (несмещённая оценка).
5. Для выборки n=42: E(X)=0.82, Var(X)=3.32. Методом моментов найти оценки параметров нормального распределения.

*(русскоязычный дубль тех же заданий про очистку данных — оставлен на исходном сайте, при переносе объединить с п.4)*

## Контрольная работа №2 (конец семестра)

1. Проверить H0: Var(X)=Var(Y) при α=0.06 против H1: Var(X)≠Var(Y) (даны две выборки X, Y по ~180 значений).
2. Очистить выборку от NA, проверить гипотезу о дискретном равномерном распределении ответов респондентов при α=0.09 (критерий согласия Пирсона).
3. Двумерная выборка (X,Y) с пропусками — удалить строки с NA, проверить незначимость коэффициента корреляции (H0: ρ=0).
4. Проверить H0: E(X)=E(Y) без предположения о равенстве дисперсий при α=0.09 (даны выборки X, Y).
5. По результатам соцопроса (с NA) — найти число вариантов ответов, число и долю ответивших "Post-Graduate", границы 0.92-доверительного интервала для доли.
