**Финансовый университет при Правительстве РФ**

## Exam instructions \ Инструкции к экзамену

- This is a closed book exam, but you will have access to computers to check your calculations.
- You have 45 minutes.
- Both questions have equal weights (30 points).
- You may be able to receive partial credit for intermediate calculations.

## Software \ Софт

2. [Interactive guide to voting systems](https://ncase.me/ballot/)
3. Telegram bot to create a poll: @ubervotebot
4. [Pivot tool](https://vanderbei.princeton.edu/JAVA/pivot/simple.html) — simplex calculator for linear programming
5. [Bimatrix Games solver](http://cgi.csc.liv.ac.uk/~rahul/bimatrix_solver/)

## Topics \ Темы

- Classification of the games (antagonistic, bimatrix, zero/positive/negative sum, simultaneous, etc.)
- Maximin and Minimax Algorithms (saddle points in pure strategies)
- Payoff matrix (Strategic form) ↔ Tree view (Extended form) transformations
- Strictly and weakly dominant and dominated strategies
- Game patterns (Stag hunt, Chicken, The battle of the sexes, Prisoner's Dilemma, Rock-Paper-Scissors, Coins Matching, Hide and Seek)
- Games against nature: Laplace, Savage, Wald, Hurwitz criteria
- Nash equilibria in mixed strategies (formulas for 2×2 and 3×3 matrices)
- Simplex Method (saddle points in mixed strategies), Duality

## Demo examination sheets \ Демо-варианты экзамена

**Example A**
1. Describe the Stag hunting game: fill in a payoff matrix, find optimal strategies (30 points)
2. Given a tree view of a game, create a payoff matrix and describe the game (30 points)

**Example B**
1. Use the linear programming method to find a solution of the game manually (10 points), in Excel (10 points), in R (10 points)
2. Given the game [5, 2] [3, 4]: draw a tree and compute optimal strategies (30 points)
